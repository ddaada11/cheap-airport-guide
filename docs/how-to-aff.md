# 邀请链接怎么填：五步，十分钟

> 这一步不做，后面所有内容都是替同行打工。
> 稿子里现在有 **15 处** 邀请链接（5 家 × 3 处），全部是 `YOUR_CODE_XXX` 占位符。填完这一个文件，15 处全部自动替换。

---

## 第一步：注册这 5 家（约 8 分钟）

按顺序注册，每家只用邮箱，不要用手机号（这个价位的机场不值得留手机号）。

| # | 机场 | 注册入口 | 注册后先做什么 |
| --- | --- | --- | --- |
| 1 | 飞鸟云 | `https://feiniaoyun.xyz/#/register` | 看套餐页有没有「传家宝 12 元/年」 |
| 2 | 杏花云 | `https://c.jichangs.com/xinghuayun` | 确认进站后是官方面板，不是二道贩子 |
| 3 | Phantom | `https://pin.dianping.men/auth/register` | 看有没有 1 元 100G 档 |
| 4 | 赔钱机场 | `https://dash.pqjc.site/register` | 看有没有 1.5 元档 + 0.1 倍率节点 |
| 5 | Kitty Network | `https://kitty.sb/#/register` | 看年付 24 元 / 128G 档 |

> 注意：这 5 家的域名都可能变。进不去就搜「机场名 + 发布页」，从它的 GitHub 发布页找新地址。**不要从搜索引擎广告位进**，这个品类冒名站极多。

---

## 第二步：在后台找「推广」页（每家 30 秒）

这 5 家用的都是 **v2board / xboard** 面板，推广页位置基本一致：

### 路径 A：左侧菜单（最常见）

登录后看左侧菜单，找这些名字之一：

```
邀请返利   /   推广中心   /   分销   /   邀请好友   /   Affiliate
```

点进去，页面上会有两块东西：

```
我的邀请码：ABC123XY
我的推广链接：https://feiniaoyun.xyz/#/register?code=ABC123XY
```

### 路径 B：直接敲地址（菜单里找不到时）

在浏览器地址栏把域名后面接上这些路径，一个个试：

```
https://你的机场域名/#/invite
https://你的机场域名/#/aff
https://你的机场域名/user/aff
https://你的机场域名/#/plan        ← 有些面板把推广放在套餐页的 tab 里
```

### 路径 C：问客服（前两个都不行时）

开工单或找在线客服，原话这样问：

> 你好，我想做推广，请问有没有邀请返利？返佣比例是多少，怎么结算？我的邀请码在哪里看？

**三个必须问清楚的问题：**

1. **返佣比例**：首单多少 %，续费还返不返（循环返佣）？
2. **结算方式**：满多少提现，多久结一次，提到哪（支付宝 / USDT）？
3. **有没有门槛**：要不要先买过套餐才能开通推广？有没有最低推广人数要求？

低价机场常见比例是 **首单 5%~15%，续费 0~5%**。别期待 20%，那是中高价位的行情。

## 第三步：把码填进 `data/my-aff.json`

打开这个文件，你会看到 5 个条目。**只需要改两个字段：`code` 和 `url`。**

### 最省事的填法：只填 code

```jsonc
{
  "aff": {
    "feiniaoyun.xyz": {
      "code": "ABC123XY",     // ← 只改这里
      "url": "",              // ← 留空
      ...
    }
  }
}
```

脚本会自动拿稿子里的原始链接，把 `code=` 后面的参数换成你的：

```
原始：https://feiniaoyun.xyz/#/register?code=YOUR_CODE_FEINIAO
填码后：https://feiniaoyun.xyz/#/register?code=ABC123XY
```

### 更保险的填法：code + url 都填

后台给你的推广链接长什么样，就原样复制进来：

```jsonc
{
  "aff": {
    "feiniaoyun.xyz": {
      "code": "ABC123XY",
      "url": "https://feiniaoyun.xyz/#/register?code=ABC123XY",
      "rate": "首单 10% / 续费 5%",
      "settle": "满 50 元支付宝提现，月结",
      ...
    }
  }
}
```

**为什么要填 `rate` 和 `settle`？** 因为稿子里的「加钱升级」那一段，你需要知道哪家的返佣高，才好决定推谁。这是给你自己看的。

### 杏花云特殊：它的入口是跳转链接

```jsonc
"c.jichangs.com": {
  "code": "你的码",
  "url": "https://c.jichangs.com/xinghuayun?code=你的码",  // ← 注意是 ? 不是 /#
  ...
}
```

如果后台给的链接格式不一样，**以后台为准**，直接复制过来。

## 第四步：跑一条命令

```bash
npm run topic
```

**成功的输出长这样：**

```
✔ 已生成 docs/topic-1yuan.md（5 家 + 5 家附录，9900 字符）
✔ 所有入口都已经是你的码
```

**失败的输出长这样：**

```
⚠ 以下 5 家的链接还是占位符，去 data/my-aff.json 填自己的码：
  飞鸟云、杏花云、Phantom、赔钱机场、Kitty Network
```

出现这个提示，说明 `code` 还是 `FILL_ME`，或者域名 key 写错了（必须是主域名，不能带 `https://`、不能带路径）。

## 第五步：验证（30 秒）

```bash
# 看稿子里还有没有占位符
findstr /C:"YOUR_CODE" docs\topic-1yuan.md
```

没有输出 = 全部替换成功。

或者直接在稿子里搜你自己的码：

```bash
findstr /C:"ABC123XY" docs\topic-1yuan.md
```

应该能看到 3 处（速览表、详情页、正文入口）。

## 常见问题

**Q：注册了但没有推广页，是不是这家不给推广？**
大概率是。低价机场很多不开 aff，或者只给大站长开。**不给推广的机场，就别放进推荐位**——把它从 `topic-1yuan.mjs` 的 `items` 里删掉，换成给推广的那家。这是这个项目唯一硬性的选品标准。

**Q：后台给的链接格式和稿子里的不一样怎么办？**
`url` 字段原样复制后台的链接，脚本会用你的 `url` 覆盖稿子里的。`code` 只用于展示。

**Q：填错了会怎样？**
稿子里会出现死链。所以第五步的验证必须做。

**Q：能不能同时挂别人的码和我的码？**
不能。一个链接只能带一个 code。而且稿子里同一条目出现两个链接会显得可疑。

**Q：5 家里只有 2 家给了推广，剩下 3 家怎么办？**
两种处理：
- 从推荐位删掉，只在「附录」里留个名字（不带链接）
- 或者留在推荐位但不给链接——**不要这么做**，读者点不动会直接关页面

正确做法：**只推给推广的那几家，宁可只写 2 家。** 2 家有佣金的推荐，比 5 家白干的推荐值钱。

2. 稿子里搜 `FILL_ME` → 无结果
3. 每个链接点一遍 → 能打开，且注册页显示的邀请码是你的
