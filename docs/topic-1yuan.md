## 三步上手

**1. 先看每 GB 成本**

表里的「每 GB」是按入门档算的。同样 100G，一元机场约 0.002 元/GB，NanoCloud 约 0.02 元/GB——先按这个数字筛掉不符合预算的。

**2. 导入客户端**

在官网后台复制订阅链接，导入 Clash Verge（Windows）/ FlClash（安卓）/ Shadowrocket（iOS），更新订阅后选延迟最低的节点。

**3. 按用量买**

轻度（每月 100~300G）：便宜机场 或 NanoCloud；中度（500~1500G）：Hneko云 或 翻墙侠；重度（2000G 以上）：一元机场的月付大流量档；设备多：飞鸟云 或 便宜机场。
