## 三、没找全。具体差在哪

### 差 1：Telegram 频道（最大缺口）

这个品类的机场**主要在 TG 推广**，不在 GitHub。一个机场可能全网只有一条 TG 频道的推广帖，里面带域名和邀请码。

没做的原因：TG 需要登录态才能搜，公开 web 预览只能看到频道首页。

**怎么补**：注册一个 TG 账号，搜这些关键词，把频道里的机场名和链接抄下来：
`一元机场`、`1元机场`、`机场推荐`、`白嫖机场`、`机场优惠`、`跑路预警`

### 差 2：YouTube 视频描述

大量低价机场**只在 YouTube 做推广**（我这次挖到的「多宝一元机场」就是 YouTube 视频里发现的）。视频简介里通常直接给注册链接。

没做的原因：视频描述要逐个视频抓，无法批量。

**怎么补**：搜「一元机场 2026」「2元机场 4K」，看播放量前 20 的视频，把简介里的链接抄下来。

### 差 3：机场导航站

`ffq.la`（403）、`jichangtuijian.vip`（连接失败）都挂了。还活着的导航站没系统扫。

**怎么补**：搜「机场导航」「机场发布页」，把能打开的导航站全部过一遍。这类站点通常一页列 50~100 家。

### 差 4：Google / Bing 搜索结果页

用 `site:` 和 `intitle:` 组合能挖到大量小站：

```
intitle:"一元机场" 2026
intitle:"机场" "12元/年"
"年付" "12元" 机场 订阅
"1元" "100G" 机场
```

没做的原因：搜索引擎反爬，批量抓要代理池。

### 差 5：已经死了的机场

跑路名单里 214 家里，很多已经不运营了。这些**不应该出现在候选池里**，但我现在还没做「自动排除」——只在附录里标了跑路记录。

### 差 6：1 元档的真实数量

按这个品类的密度估算：**全网同时活着的 1~2 元档机场大概 20~40 家**。我现在找到 12 家真 1 元档 + 22 家 1~7 元档候选，覆盖率大概 **50%~60%**。

## 四、「找全」的操作定义

这个品类**不存在绝对找全**——每天都有新站开、每天都有站跑。所以「找全」的实际定义是：

> **当你连续扫 3 个新渠道，都没有发现新的 1 元档机场时，就算这一轮找全了。**

按这个标准，现在扫了 4 类渠道（GitHub / 测评站 / 跑路名单 / 面板），还有 4 类没扫（TG / YouTube / 导航站 / 搜索引擎）。

**所以现在的状态是：够写第一篇 5 家的稿子，但不够写「全网最全」。**

## 六、怎么复现这套东西

```bash
npm run harvest    # 快照 18 个 GitHub 源的原文到 ref/sources/
npm run enrich     # 双解析器抽字段 → data/facts.json
npm run discover   # 从带注册链接的源捞域名 → data/pool.json
npm run paolu      # 解析跑路名单 → data/paolu.json
npm run merge      # 名字归一化合并 → data/shortlist.json + .csv
npm run probe      # 打面板接口刷官方价（在你自己的网络跑）
npm run topic      # 渲染专题稿 → docs/topic-1yuan.md
npm run xlsx       # 出 Excel 选品表
```

每一步的中间产物都在 `data/` 下，可以单独检查、单独重跑。**没有任何一步依赖「我记得」——全部可复现。**
