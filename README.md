## 常见问题

### 便宜机场哪个好？
看每 GB 成本，不看「几元一个月」。同样 100G，有的收 0.2 元、有的收 2 元，差 10 倍。预算最紧就选每 GB 0.002~0.006 元那一档，日常刷视频、查资料完全够用。

### 一元机场还能用吗？
「一元机场」这个品类里，真正月付 1 元的站大部分已经关站了。现在能正常用的，基本是「年付 12~13 元、折合每月 1 元」这种形态。本文收录的都是官网能打开、价格能核实的。

### 便宜机场和贵机场差在哪？
主要差在线路。低价档走公网直连，晚高峰（20:00–23:00）会慢；高价档租的是 IPLC / IEPL 专线，晚高峰不明显。如果只是白天用、或者当备用，低价档够用；如果要开视频会、跑大流量任务，加钱上专线更省心。

### 机场订阅怎么导入 Clash / 小火箭？
1. 在机场后台复制**订阅链接**（那一长串 URL，不是节点二维码）。

2. Windows 装 Clash Verge，安卓装 FlClash，iOS 装 Shadowrocket（小火箭）。

3. 在客户端里「导入订阅」→ 粘贴链接 → 更新 → 选延迟最低的节点。

4. 订阅链接等同于账号密码，**不要发给任何人**。

### 为什么不推荐一次买三年？
三年付确实更便宜（本文里有 36 元三年的），但这个价位的机场平均寿命以月计。第一次买，一律选最短周期，跑顺了再考虑长期。
